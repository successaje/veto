The real reasons are the ones nobody says out loud

Someone is pregnant and hasn’t told anyone. Someone is sober. Someone can’t afford it this week, or can’t manage the stairs, or would rather not run into their ex behind the bar.

So the group chat picks somewhere, and one person quietly has a bad night, or invents an excuse not to come. A poll doesn’t help: it still asks people to say what they don’t want to say.

How it works

Three parties, and each one sees only its part

  1. The cloud

    Finds real places from the public plan

    The host types “dinner Saturday near Riverside, relaxed”. Gemini, grounded in Google Maps, proposes up to ten places. That sentence is all the cloud ever sees.

  2. Your phone

    Checks each place against your private note

    An AI model running on your device reads your note and turns it into limits. Plain code rules out anything that breaks one; the model only ranks the rest. You see your own result before anything is sent.

  3. The group

    Learns what works for everyone, and nothing else

    Your phone sends only +1s to anonymous counters. Nobody, including the host, can see the counts until the last person has voted. Then everyone sees the winner.

Proof, not promises

This is everything the database knows about your vote

A vote is one batch of increments. Security rules allow exactly one per person, cap each increment, and keep the totals hidden until everyone is done. There is no field for a reason, and no record of who chose what.

The app also keeps a list of every AI call and database write it makes, so you can check: your note never appears in it.

Hybrid AI, on purpose

Where each part runs

A cloud-only app can’t keep the promise. A phone-only app can’t find real places. Veto routes each step with Firebase AI Logic.

Step Runs Why
Reading the plan Device if ready, else cloud Public text; fastest wherever it runs
Finding places Cloud + Google Maps Needs current, real places
Understanding your note This device only The promise
Checking each place for you This device only Derived from your note, so private too
“Why this works” Device if ready, else cloud Uses only the winner’s public details

No on-device AI in your browser? You vote by hand. Veto never falls back to the cloud for anything private.
